# Katkı

Türkçe · English: [CONTRIBUTING.md](../../.github/CONTRIBUTING.md)

Yardımınız için teşekkürler! Sade tutalım:

1. Büyük değişiklikler için önce bir issue açın, fikirde anlaşalım.
2. Fork'layın, bir dal açın, değişikliğinizi yapın. Değişiklikler küçük ve odaklı olsun.
3. `npm install` sonra `npm test` çalıştırın; tüm testler geçmeli. Derleme: [BUILD.md](BUILD.md).
4. Pull request açın ve şablonu doldurun.

Proje kuralları: ağ çağrısı yok, oyun belleği okuma yok, kod enjeksiyonu yok, genel tuş kancası yok. Katkılar GPL-3.0-or-later ile lisanslanır.
