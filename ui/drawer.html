Data

Traffic recordings help find new packets. They are saved in the "kayitlar" folder inside the data folder.

What it does

Passively reads a copy of the game's network traffic with Npcap, the way DPS meters do. It makes no network calls of its own, reads no game memory, has no key hook and injects no code into the game. It only looks at the process and connection list to find out whether AION2.exe is running and which connections it uses. It never sends or changes packets.

Main features

DPS and damage, boss and dungeon history, boss timers, player ratings and blacklist, voice alerts, and position lock with Ctrl+Shift+K.

DPS

Damage is split into fights; a fight ends after the set idle time. Browse the last 10 with the arrows, click a row for its skill breakdown, click a skill for its details.

Cooldowns

The server sends only when a skill is used, not its cooldown (except a few, like Deadshot). Type the cooldown or let it be learned from the shortest gap between two uses.

Your character

Found automatically by matching the moment you press a skill with the server's reply. If it's wrong, type your character name in the box above.
